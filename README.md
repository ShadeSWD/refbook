# refbook — Инженерный справочник кластера

Единый источник нормативных данных для учебных сайтов кластера: оцифрованные
сортаменты ГОСТ, справочные константы материалов и формулы Правил РМРС. На
любую строку любой таблицы можно сослаться прямой ссылкой; данные и расчёты
доступны программно — как встраиваемые JS-библиотеки и HTTP API.

**Прод:** https://shadeswd.duckdns.org/ref/

## Содержание
- `site/` — сам справочник (чистые HTML/CSS/JS)
  - `index.html` — обзор
  - `sortament.html` + `gost-*.html` — сортаменты ГОСТ (полособульбы, уголки,
    двутавры, швеллеры, трубы, толщины листа) с массами, моментами инерции и
    первоисточниками; `naca.html` — профили NACA
  - `materials.html` — материалы и среды (сталь, пресная и морская вода, воздух)
  - `rmrs.html` — живые калькуляторы формул РМРС (волновые моменты, W_min,
    допускаемые напряжения, площадь руля, период качки)
  - `terms.html` — термины; `ship.html`, `sites.html`, `sources.html`
  - `api.html` — документация встраивания библиотек и HTTP API
  - `assets/` — `style.css`, `site.js`, `tabview.js`
  - `lib/` — встраиваемые/серверные библиотеки: `rmrs.js` и `rmrs-graph.js`
    (формулы с пошаговыми подстановками), `naca.js`, `tables.js` (данные)
  - `api/tables/*.json` — статические таблицы (CORS открыт), отдаёт nginx
- `api-server/server.js` — node-сервис calc-API: тонкая HTTP-обёртка над теми
  же `lib/rmrs.js` и др. (единый источник формул); эндпоинты `/calc/…`,
  `/naca`, `/ship/…`, `/terms`
- `deploy/` — docker-compose + конфиг nginx
- `tests/` — тесты целостности сайта (pytest)

## Стек
Статика (HTML/CSS/ванильный JS) на nginx:alpine + отдельный node-сервис
calc-API. Раздача — nginx в Docker с чистыми URL
(`try_files $uri $uri.html $uri/`) и `Access-Control-Allow-Origin: *` (данные
и библиотеки встраиваются на другие сайты кластера).

## Архитектура API
- **Данные** — статические JSON: `GET /ref/api/tables/<name>.json`.
- **Расчёты** — динамические, через node-сервис (host-nginx проксирует
  `/ref/api/` → `127.0.0.1:8072`): `GET /ref/api/calc/<fn>?…`,
  `/ref/api/naca`, `/ref/api/ship/…`, `/ref/api/terms`. Ответ содержит и
  значения, и пошаговые подстановки формул.

## Запуск локально
```bash
cd deploy && docker compose up -d   # проект называется refbook (name: обязателен!)
```
Поднимается два контейнера: `refbook-web` (`127.0.0.1:8067`) и `refbook-api`
(`127.0.0.1:8072`). Наружу отдаётся через host-nginx: `location /ref/`.

## Тесты
```bash
pip install pytest --break-system-packages -q
python3 -m pytest tests/ -q
```
Тест-кит параметризуется по файлам: для каждой HTML-страницы проверяет разбор,
отсутствие дублей `id` и целостность локальных ссылок/ассетов (с учётом
clean-URL nginx), для каждого JS — синтаксис через `node --check`.

Проверяются только статические файлы `site/`. Динамические маршруты calc-API
(`api/calc`, `api/naca`, `api/ship`, `api/terms`) не отображаются в файлы —
они исключены из проверки целостности ссылок (см. `_DYNAMIC_ROUTES` в
`tests/test_site.py`); статические `api/tables/*.json` проверяются как обычно.
