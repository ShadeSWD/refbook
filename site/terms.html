Словарь терминов

Определения терминов, встречающихся на сайтах кластера. На каждый термин есть якорная ссылка; определения выдаются по API — на сайтах кластера они появляются всплывающими подсказками при наведении на термин.

Расчётные формулы курсов — в банке формул: там у каждой формулы расшифрованы все обозначения, указаны единицы, границы применимости и глава, где формула выводится.

API: весь словарь JSON · api/terms?q=метацентр — поиск по слову.
