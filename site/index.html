Инженерный справочник

Единое место, откуда все сайты кластера берут нормативные данные: оцифрованные таблицы сортаментов ГОСТ, справочные константы материалов и формулы Правил РМРС. На любую строку любой таблицы можно сослаться прямой ссылкой из любой задачи; данные и расчёты доступны программно — как встраиваемые библиотеки и HTTP API.

📐 Сортаменты ГОСТ

Полособульбы, уголки, двутавры, швеллеры, трубы, толщины листа — с массами, моментами инерции и методикими.

🧱 Материалы и среды

Сталь, пресная и морская вода, воздух: плотности, модули, g — каждая константа со ссылкой на норматив.

⚓ Формулы РМРС

Волновые моменты, минимальный момент сопротивления, допускаемые напряжения, площадь руля, период качки — живые калькуляторы.

Σ Банк формул

Формулы всех курсов кластера в одном месте: обозначения с единицами, границы применимости и ссылка на главу, где формула выводится.

🚢 Суда-прототипы

Шестнадцать учебных вариантов судов: размерения, коэффициенты полноты, метацентрические радиусы и кривые элементов теоретического чертежа — с передачей выбранного судна в решатели кластера.

🔌 Библиотеки и API

rmrs.js (формулы с пошаговыми подстановками) и tables.js (данные); HTTP API /ref/api/… для любых программ.

Правила честности

Каждая таблица хранит URL источника и дату сверки; значения, которые не удалось увидеть в методических расчётах, в таблицу не попадают. Контрольные сверки описаны в примечаниях (например, полособульб 20а по ГОСТ — 21,47 кг/м; часто встречающееся значение «21,45» — это масса уголка 140×10 по ГОСТ 8509).
