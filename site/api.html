Библиотеки и API

У справочника две библиотеки: rmrs.js — формулы и полноценные расчёты (каждая функция возвращает не только числа, но и пошаговые подстановки), и tables.js — оцифрованные таблицы ГОСТ. Оба слоя доступны и как подключаемый скрипт, и как HTTP API — их использует сам справочник (страница РМРС) и решатели сайтов кластера.

1. Встраивание на страницу

<script src="https://shadeswd.duckdns.org/ref/lib/rmrs.js"></script>
<script>
  const r = RMRS.waveMoments({ L: 100, B: 16, Cb: 0.7 });
  console.log(r.values);   // { cw: 7.92, Mw_hog: 168571, Mw_sag: -195188 }
  console.log(r.steps);    // [{f:'c_w = …', sub:'10,75 − …', res:7.92}, …]
</script>

<script src="https://shadeswd.duckdns.org/ref/lib/tables.js"></script>
<script>
  const pb = await REFTAB.row('gost-21937', '20а');
  console.log(pb['Масса 1 м, кг']);   // 21.47
</script>

2. HTTP API

Данные (статические JSON, CORS открыт):

GET /ref/api/tables/gost-21937.json   → вся таблица с колонками и источником
GET /ref/api/tables/materials.json

Расчёты (тот же rmrs.js, исполняется на сервере — единый источник формул):

GET /ref/api/calc                                → список функций
GET /ref/api/calc/waveMoments?L=100&B=16&Cb=0.7  → { values, steps, rule }
GET /ref/api/calc/rollPeriod?B=16&d=5.6&L=100&h=0.38

Попробовать прямо сейчас: api/calc/waveMoments?L=100&B=16&Cb=0.7

3. Зачем так

Формулы правил и таблицы сортаментов нужны каждому предмету: общая прочность берёт волновые моменты и W_min, технология — полособульбы и трубы, устройства — площадь руля, статика — период качки. Вместо копий в каждом сайте — один проверенный источник с первоисточниками и датами сверки; пошаговые подстановки в ответе позволяют любому решателю не просто получить число, а показать студенту, откуда оно взялось.
