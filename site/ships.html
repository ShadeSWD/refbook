Банк судов-прототипов

Шестнадцать реальных учебных вариантов судов, оцифрованных в единую таблицу: главные размерения, характеристики объёма и ватерлинии, коэффициенты полноты, метацентрические радиусы и кривые элементов теоретического чертежа (КЭТЧ) по осадкам. Любое судно можно взять как прототип: кнопка в карточке передаёт его размерения в расчёт главных элементов и в расчёт посадки и остойчивости. Источник данных — варианты заданий кафедры проектирования судов СПбГМТУ; публикуются только извлечённые числовые характеристики, исходные файлы заданий не выкладываются.

Прототипы

δ — коэффициент общей полноты, α — полноты ватерлинии, β — полноты миделя, φ — призматический; звёздочкой отмечена высота борта, восстановленная как H = T + минимальный надводный борт (она известна только там, где в задании есть сводка гидростатики). Ширина в таблице — расчётная (по ватерлинии при проектной осадке): у части вариантов «ширина на миделе» в шапке файла снята не по мидель-шпангоуту.

Карточка судна

Как эти данные устроены

Каждый вариант — результат расчёта гидростатики по корпусу, построенному в судостроительной CAD-системе. Сводка даёт элементы при проектной осадке, таблица КЭТЧ — те же элементы как функции осадки. Связи между величинами — стандартные соотношения статики корабля:

$$\delta = \frac{V}{L\,B\,T},\qquad \alpha = \frac{A_w}{L\,B},\qquad \beta = \frac{A_m}{B\,T},\qquad \varphi = \frac{V}{A_m L} = \frac{\delta}{\beta}$$

Метацентрические радиусы получаются из моментов инерции площади ватерлинии относительно центральных осей, а аппликата метацентра — от центра величины:

$$r = \frac{I_x}{V},\qquad R = \frac{I_f}{V},\qquad z_m = z_c + r,\qquad z_{M} = z_c + R$$

Число тонн на сантиметр осадки \(q = \rho A_w / 100\), момент дифферентующий на 1 см \(m_1 = D\,(z_c + R - z_g)/(100\,L)\). Абсциссы \(x_c\) и \(x_f\) в исходных данных отсчитываются от кормового перпендикуляра (x = 0), поэтому в карточке они приведены и от миделя: для судна с нормальным дифферентом на корму разность \(x_c - x_f\) невелика и по знаку соответствует смещению центра величины в нос; при \(x_c - x_f < 0\) центр величины смещён к корме относительно центра тяжести площади ватерлинии.

Методика работы с КЭТЧ — практикум кафедры (расчёт посадки по кривым элементов, определение изменения осадок при приёме груза). Полные расчёты по этим данным — на сайтах «Статика корабля» и «Проектирование судов».

Программный доступ

Вся таблица одним файлом: api/tables/ships.json (CORS открыт). В файле: ships — массив судов (L_pp, L_max, B, B_eff, T, H_est, rho, блок hydro — сводка гидростатики, блок design — элементы при проектной осадке, kech — таблица кривых элементов строками по колонкам kech_columns, sac — площади шпангоутов), units — единицы, labels — расшифровки обозначений, types — типы судов. Величины, которых нет в исходных данных, в файл не попадают.
